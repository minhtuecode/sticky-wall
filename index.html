Nhập từ file

Hỗ trợ .txt, .md, .json (mảng chuỗi, mảng đối tượng, hoặc file notes.json của app). Thẻ và nguồn bên dưới sẽ gán cho mọi ghi chú nhập từ file .txt/.md.

Ảnh thật được tạo tự động mỗi sáng trên GitHub, bố cục tương tự bản xem trước này nhưng cách chọn ghi chú theo ngày.
